# 💱 Currency Converter (Java GUI)

A modern Java Swing-based Currency Converter that uses real-time exchange rates via API.

---

## 🚀 Features

* 🌍 Real-time currency conversion
* 💻 Java Swing GUI
* 🔄 Swap currencies
* 📜 Conversion history
* 🎨 Styled user interface

---

## 🛠️ Technologies Used

* Java (Swing)
* ExchangeRate API
* JSON Library

---

## ▶️ How to Run

```bash
javac -cp ".;lib/json-20210307.jar" CurrencyConverterGUI.java
java -cp ".;lib/json-20210307.jar;." CurrencyConverterGUI
```
